# 邮箱验证功能说明

## 功能概述

已为应用添加完整的邮箱验证功能，确保用户注册后需要验证邮箱才能登录。

## 已实现的功能

### 1. 注册流程更新
- ✅ 注册后自动发送验证邮件
- ✅ 如果邮箱需要验证，跳转到验证页面
- ✅ 如果邮箱已验证或不需要验证，直接进入应用

### 2. 验证页面 (`app/(auth)/verify-email.tsx`)
- ✅ 显示验证说明
- ✅ 重新发送验证邮件功能
- ✅ 60秒冷却时间防止频繁发送
- ✅ 检查验证状态按钮

### 3. 登录流程更新
- ✅ 检查邮箱是否已验证
- ✅ 未验证邮箱无法登录
- ✅ 显示友好的错误提示

### 4. 认证上下文更新 (`contexts/authContext.tsx`)
- ✅ `signUp()` - 返回是否需要验证
- ✅ `resendVerificationEmail()` - 重新发送验证邮件
- ✅ `verifyEmail()` - 验证邮箱（通过 token）
- ✅ `signIn()` - 检查邮箱验证状态

## 使用流程

### 用户注册
1. 用户填写注册表单
2. 点击"Sign Up"
3. 系统发送验证邮件
4. 跳转到验证页面

### 邮箱验证
1. 用户打开邮箱
2. 点击验证链接
3. 返回应用
4. 点击"我已验证邮箱"按钮
5. 进入应用主界面

### 重新发送验证邮件
1. 在验证页面点击"重新发送验证邮件"
2. 系统发送新的验证邮件
3. 60秒内不能重复发送

## 配置要求

### InsForge 后端配置
需要在 InsForge 控制台配置：

1. **邮箱服务提供商**
   - 配置 SMTP 设置
   - 或使用 InsForge 默认邮件服务

2. **验证链接回调 URL**
   - 设置验证成功后的重定向 URL
   - 格式：`https://your-domain.com/auth/verify-email`

3. **邮件模板**（可选）
   - 自定义验证邮件模板
   - 包含验证链接

### 环境变量
确保 `.env` 文件中设置了：
```env
EXPO_PUBLIC_INSFORGE_BASE_URL=https://your-insforge-url.com
EXPO_PUBLIC_INSFORGE_ANON_KEY=your-anon-key
```

## API 方法说明

### `signUp(email, password, name?)`
注册新用户并发送验证邮件。

**返回**:
```typescript
{
  needsVerification: boolean  // 是否需要邮箱验证
}
```

### `resendVerificationEmail(email)`
重新发送验证邮件到指定邮箱。

### `verifyEmail(token)`
通过验证 token 验证邮箱（通常通过邮件链接调用）。

### `signIn(email, password)`
登录时检查邮箱是否已验证，未验证则拒绝登录。

## 注意事项

1. **邮件服务配置**
   - 确保 InsForge 后端已配置邮件服务
   - 验证邮件可能进入垃圾邮件文件夹

2. **验证链接**
   - 验证链接通常包含 token
   - 需要在 InsForge 控制台配置回调 URL

3. **用户体验**
   - 提供清晰的验证说明
   - 支持重新发送验证邮件
   - 显示友好的错误提示

4. **安全性**
   - 验证 token 有时效性
   - 防止暴力重试（60秒冷却）

## 故障排除

### 问题：收不到验证邮件
- 检查垃圾邮件文件夹
- 确认邮箱地址正确
- 检查 InsForge 邮件服务配置
- 使用"重新发送"功能

### 问题：验证链接无效
- 检查 token 是否过期
- 确认回调 URL 配置正确
- 尝试重新发送验证邮件

### 问题：登录时提示未验证
- 确认已点击邮件中的验证链接
- 检查邮箱验证状态
- 尝试重新发送验证邮件
